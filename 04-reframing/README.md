# 04 - Reframing

Tools in this phase:

- **structured-analysis-of-analogies** (hub route) - Score and compare analogies against a working hypothesis
- **Analogies Collection** (ChatGPT agent) - Collect candidate analogies
- **Analogies Processor** (ChatGPT agent) - Process and screen analogies before scoring

Run from repo root: `node start-all.js` and open the hub at http://localhost:3000.
